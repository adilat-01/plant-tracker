מסמך אפיון פרויקט: מערכת ניהול צמחים חכמה ("Plant Manager")
1. סקירת העל של המערכת
מערכת Web אישית וקהילתית לניהול, מעקב ואוטומציה של צמחי הבית והגינה. המערכת משלבת זיהוי צמחים אוטומטי מבוסס תמונה באמצעות בינה מלאכותית (Gemini API), שולפת אוטומטית את הנחיות ההשקיה והטיפול, מרכזת את הנתונים ב-Google Sheets, ומציגה ממשק ויזואלי המחולק לאזורים בבית (חדרים). בנוסף, המערכת כוללת מערכת משתמשים, ניהול בתי אב משותפים באמצעות קוד שיתופי, ואוטומציות לשליחת התראות מייל לזמני השקיה.

2. חלוקה למרחבים (Rooms)
מסך הבית הראשי של המערכת יחולק לכרטיסיות או אזורים (Sections) לפי מיקום הצמחים בבית ובחצר:

סלון (למשל: סקנדפסוס / פוטוס כסף).

גינה (למשל: פורטולקריה אפריקאית).

כניסה קדמית (למשל: אדן החלון עם דיפלדניה, פטוניה ופלפל נוי).

3. פלואו משתמש (User Flow)
שלב 0: רישום, התחברות וניהול בית משותף (Authentication & Household)
הרשמה והתחברות: המשתמשת נכנסת לאתר ויכולה להירשם עם שם משתמש וסיסמה (או להתחבר).

יצירת או הצטרפות לבית:

משתמש חדש יכול ליצור "בית" חדש (למשל: הבית בבנימינה), והמערכת מייצרת עבורו קוד שיתופי ייחודי.

משתמש נוסף (כמו שחר) יכול להירשם לאפליקציה ולהזין את הקוד השיתופי כדי להתחבר לאותו הבית ולראות/לנהל את אותם הצמחים במשותף.

שלב 1: כניסה למערכת ותצוגה ראשית (Dashboard)
המשתמשת מתחברת ורואה את לוח הבקרה של הבית המשותף שלה.

המסך מציג את הצמחים מחולקים ויזואלית לפי חדרים (סלון, גינה, כניסה קדמית).

לכל צמח מוצגים הנתונים הבאים:

תמונה ושם הצמח שזוהה.

סטטוס השקיה (לדוגמה: "הגיע הזמן להשקות! 🚰" בצבע אדום, או "הכל טוב 🌿" בצבע ירוק).

מספר הימים שנותרו עד ההשקיה הבאה.

כפתור מהיר: "השקיתי היום".

שלב 2: הוספת צמח חדש באוטומציה מלאה (Add Plant Flow)
המשתמשת לוחצת על כפתור "+ הוסף צמח".

נפתח חלון קטן (Modal) שבו היא:

מעלה או מצלמת תמונה בלבד של הצמח.

בוחרת את החדר הרצוי מתוך רשימה נפתחת (סלון / גינה / כניסה קדמית).

היא לוחצת על "זהה ושמור":

המערכת שולחת את התמונה אל Gemini API עם הנחיה לזהות את הצמח.

ה-API מנתח את התמונה ומחזיר אוטומטית מבנה נתונים (JSON) הכולל: שם עברי מדויק, תדירות השקיה מומלצת בימים, תנאי תאורה וטיפים.

הנתונים נשמרים אוטומטית במסד הנתונים יחד עם שייכות לבית, החדר, תאריך ההוספה ותאריך ההשקיה האחרון.

החלון נסגר, והצמח מופיע מיד בכרטיסייה המתאימה בחדר הנבחר.

שלב 3: עדכון שוטף ואוטומציות (Day-to-day Management & Alerts)
עדכון ידני: לאחר השקיית הצמח במציאות, לחיצה על "השקיתי היום" מעדכנת את תאריך ההשקיה האחרון ומאפסת את הטיימר לכל בני הבית.

אוטומציות והתראות מייל (עתידי/הרחבה):

סקריפט יומי (ב-Google Apps Script או שרת) ירוץ ברקע ויבדוק אילו צמחים הגיע זמנם להשקיה.

כאשר צמח דורש השקיה, המערכת תשלח התרעת מייל אוטומטית לכתובת המייל של המשתמשת ושל שאר חברי הבית הרשומים, עם רשימת הצמחים שצריכים מים להיום.

4. ארכיטקטורה טכנית (Tech Stack)
Frontend: React / Next.js מנוהל ומאוחסן בחינם דרך Vercel.

Backend / API: Vercel Serverless Functions / Google Apps Script לטיפול בלוגיקה, קריאות מול Gemini API, ניהול משתמשים וקוד בתי אב.

AI Engine: Gemini API (ניתוח ויזואלי של התמונה לצורך זיהוי צמח ושליפת פרמטרים בוטניים).

Database: Google Sheets API או מסד נתונים קליל (כמו Supabase/Firebase אם נדרשת ניהול משתמשים וסיסמאות מתקדם יותר, או שמירת טבלאות נפרדות בגוגל שיטס).

Notification Service: שירות שליחת מיילים (כמו Resend, SendGrid או Google Apps Script MailApp) לשליחת תזכורות ההשקיה לחברי הבית
